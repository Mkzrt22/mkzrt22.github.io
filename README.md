# mkzrt22.github.io

Adresses courtes vers le site de FluxTV (https://mkzrt22.github.io/FluxTV-iOS/).

- `mkzrt22.github.io` : le site.
- `mkzrt22.github.io/tiktok`, `/youtube`, `/instagram`, `/facebook`, `/whatsapp`, `/x`, `/discord`, `/snapchat`, `/forum`, `/presse`, `/qr`, `/store`, `/partage` : le site, avec la visite comptée pour ce réseau (`?s=…`) sur la page de statistiques.
- `mkzrt22.github.io/apk` : l'APK Android, à saisir dans Downloader.
- `mkzrt22.github.io/soutenir` : la page de dons (Ko-fi, et plus tard PayPal et crypto). Le bouton du site et le QR code de l'app Android y mènent : on peut changer de plateforme sans mettre à jour l'app.
- Toute autre adresse (majuscules, alias comme `/tt` ou `/yt`, `fluxtv-ios` en minuscules) est redirigée par `404.html`.
